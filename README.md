# 物流异常看板

燕文 / 递四方后台异常订单 → 浏览器自动采集 → 马帮 ERP 匹配 → 单页看板。

在线看板： https://echo-ai-use.github.io/logistics-abnormal-dashboard/

## 模块

| 模块 | 说明 |
|---|---|
| 全部异常件 | 所有异常订单汇总 |
| 仓内/库内异常 | 燕文仓内异常 · 递四方库内异常 |
| 尾程/海外异常 | 递四方海外退件 · 海关查验 · 服务商异常反馈 |
| 待自提 · 到达待取 | 燕文待领取 · 递四方到达待取 |
| 可重派件 | 所有可重派的件 |

## 数据

- `data.json` 由本地采集 + 匹配流程生成，包含异常单明细与马帮订单字段。
- 单号口径：燕文主单号取**转单号**(exchangeNumber)，递四方主单号取**服务商单号**(serviceHawbCode)，原单号保留在「原始运单号」列。
- 马帮 ERP 全程**只读**，仅调用查询类接口。

_本仓库内容由本地脚本自动生成并上传。_
